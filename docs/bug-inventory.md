## 確認した方法
- ビルド結果の全37ページについて、サイト内リンクと画像（href / src）がファイルとして存在するかを確認
- 外部リンク74件の HTTP ステータスを確認
- 画像のファイルサイズと、ページごとに読み込む画像の合計サイズを集計

- 主要9ページをスマホ幅（375px）で開き、横にはみ出さないかを確認 → 問題なし
- トップページのコンソールエラーと通信エラーを確認 → 問題なし
